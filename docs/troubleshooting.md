# 故障排查 / Troubleshooting

按现象归类，给出「在哪台设备上操作」与「如何解决」。工具不会自动替你判定手机定位成功，
所有需要你本人确认的步骤都会在界面里明确提示。

## 1. 设备与驱动

### 未检测到设备
- 在**电脑**上：确认数据线支持数据传输（不是纯充电线），且已安装 Apple Mobile Device USB 驱动。
- 在**iPhone**上：解锁手机，若弹出「信任此电脑」，点击「信任」并输入锁屏密码。
- 在**电脑**上：点击「检测设备」重新扫描。
- 缺驱动时：界面会弹出警示并询问是否打开 Apple 官方页面（安装 iTunes 或 Microsoft Store「Apple 设备」），**不会静默安装**。

### 已信任但仍连不上
- 重新插拔数据线；换一个 USB 口（优先直连主机后置口，避免集线器）。
- 在电脑上退出并重新打开本工具。

## 2. 认证材料

### 提示「需要配件认证，但尚未配置认证材料」
- 属**预期阻断**：本工具不内置、不分发任何 MFi 证书或私钥。
- 在**电脑**上：于「认证材料」区域填入你合法持有的 `certificate.p7b` 与 `identity.pk8`，或设置环境变量
  `OUYE_LOCATION_STUDIO_CERT_FILE` / `OUYE_LOCATION_STUDIO_KEY_FILE`。
- 合法获取途径与合规边界见 `docs/real_device_path.md`。

### 认证失败（设备拒绝，AA04）
- 证书与私钥不匹配、不是 P-256、或不被设备接受。
- 确认两者来自同一份合法配件身份；`identity.pk8` 须为未加密 DER PKCS#8。

## 3. 定位会话

### 已发送坐标，但手机位置未变
- 本工具**不会**把「发送成功 / ACK / 引擎 active」判定为定位成功。
- 在**iPhone**上：打开地图，人工确认蓝点是否移动到目标位置；确认目标 App 使用的定位来源与健康 App 设置。
- 若未生效，先确认会话仍处于「正在发送定位信息」状态且无报错横幅。

### 停止后位置未恢复
- 会话结束会弹出「定位恢复确认」。
- 在**iPhone**上：打开地图查看蓝点是否回到真实位置；若未恢复，稍等几秒，或重新插拔设备、关闭再开启定位。

## 4. 会话与退出

### 重复点击「开始定位」
- 已有会话运行时「开始定位」按钮被禁用，不会重复发起。

### 会话中关闭窗口
- 关闭窗口会先请求停止并等待会话清理（最多数秒），异常退出会尽力关闭链路与连接。

### 设备中途断开
- 界面会显示错误横幅；重新插拔后点击「检测设备」再开始。

## 5. 界面

### 主题 / 缩放
- 窗口右上角「主题」按钮在浅色与深色之间切换，选择会被记住。
- 窗口可缩放，最小尺寸为 640×600；日志区会随窗口拉伸。

### 许可页显示「未找到捆绑的 LICENSE 文件」
- 源码运行：确认在项目根目录（含 `LICENSE` 与 `THIRD_PARTY_NOTICES.md`）下运行。
- 打包运行：该问题不应出现（spec 已打包两份文件到资源目录）。
