# 本地认证 / Local authentication

设备先请求证书，随后发送挑战。本地密钥校验成功**不**证明设备接受该身份；设备的 `AA05` 响应
才是认证结果。

## 外部配置接口

认证助手是一个常驻子进程，标准输入/输出为一行一个 JSON 对象，标准输出专用于协议响应。
私钥只存在于该助手进程内，不进入引擎进程。

证书请求：

```json
{"op":"certificate"}
```

常规 MFi 响应：

```json
{"type":"mfi","certificate":"BASE64_PKCS7_CONTAINER"}
```

签名请求与响应：

```json
{"op":"sign","challenge":"BASE64_CHALLENGE"}
{"signature":"BASE64_SIGNATURE"}
```

提供者可返回 `{"error":"描述"}` 拒绝请求。助手不会把原始输入、凭证路径或密钥材料写入错误信息。

通用客户端同样接受外部 BAA 提供者返回
`{"type":"baa","certificate":"BASE64_LEAF_DER","intermediate":"BASE64_CA_DER"}`。
BAA 的 `AA01` 含 `(0, leaf)`、`(1, 字节 1)`、`(2, intermediate)`；常规 MFi 的 `AA01` 仅含
`(0, 证书容器)`。两种情况下 `AA03` 在参数 0 携带签名字节。本仓库不包含 BAA 凭证签发实现。

## 内置 MFi-v3 助手

配置以下环境变量（GUI 会在启动会话前设置）：

| 变量 | 所需文件 |
| --- | --- |
| `OUYE_LOCATION_STUDIO_CERT_FILE` | DER PKCS#7 证书容器 |
| `OUYE_LOCATION_STUDIO_KEY_FILE`  | 未加密 DER PKCS#8 P-256 私钥 |

助手校验证书容器结构并保证恰好存在一个与私钥匹配的非 CA P-256 叶子证书；限制输入大小，
拒绝格式错误或身份不明确的文件。这些校验**不**验证 Apple 信任、吊销状态或使用该凭证的授权。

MFi-v3 挑战必须恰好 32 字节，且已是 SHA-256 摘要。助手使用预哈希 ECDSA，再将 DER 签名转为
对端要求的 64 字节 `r || s` 形式。对挑战再次哈希或返回 DER 签名都会改变结果。

助手只读取本地文件，不自动获取身份。请使用你自己合法持有的匹配身份。测试生成的短时自签名
身份仅用于离线测试，测试后即删除。

## 阻断项（如实说明）

若认证材料的授权问题阻碍完整发行：

1. 本应用**不内置、不分发、不自动导入**任何证书或私钥；
2. 未配置时，配件认证会如实失败并提示，不伪造成功、不采用绕过方案；
3. 认证材料的获取、授权与分发责任由使用者自行承担。

## 诊断

常规事件报告消息标识、参数大小与状态迁移，不输出证书、挑战、签名或私钥。
